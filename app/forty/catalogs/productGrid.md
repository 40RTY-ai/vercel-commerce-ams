# productGrid

A titled grid of products, each drawn as this store's product tile — image, name and price — linking to the product's page; the default answer to any product question.

## When to Use

The visitor wants to see or browse specific products — "show me snowboards", "something for a first season", "what's new". The default way to answer any product question.

## Don't Use When

The visitor is orienting between categories rather than choosing items — use `collectionList`. They are weighing a few specific products — use `comparisonTable`. They want one answer — use `productDetail`.
